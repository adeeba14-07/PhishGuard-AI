About PhishGuard AI

🎯 Project Overview

PhishGuard AI is an intelligent phishing website detection system that uses Machine Learning to protect users from online threats. The project analyzes URL patterns and characteristics to identify potentially malicious websites in real-time.

🤖 Technology Stack

  • Backend: Python Flask
  • Machine Learning: Scikit-learn (Random Forest Classifier)
  • Frontend: HTML5, CSS3, JavaScript
  • Dataset: 11,055 URL samples with 30 features
  • Accuracy: 92.6%
